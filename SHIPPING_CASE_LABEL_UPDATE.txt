Order Forms: mark one or more POs using the Shipping Case Labels checkboxes, or Mark all. Click Generate Shipping Case Labels. Fill in Case Weight and SCC/GTIN for each selected PO, then click Generate PDF Files. One PO downloads a PDF. Multiple POs download a ZIP containing separate PDF files. Individual PDF download links remain available in the window. All fields are validated before any files are generated. The existing two-labels-per-page layout is preserved. Pallet selection uses its original separate checkboxes.
