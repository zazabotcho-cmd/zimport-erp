This package contains the complete deployable ZIMPORT browser application plus its Supabase database schema and secure user-management Edge Function.

It is not a hosted website by itself. A live login requires:
- your Supabase project,
- the database schema installed,
- the manage-users Edge Function deployed,
- and these files uploaded to an HTTPS web host.

Open DEPLOYMENT_CHECKLIST.txt and complete the steps in order.
